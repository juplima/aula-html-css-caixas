# Aulas de Desenvolvimento Web

Repositório com projetos e exercícios desenvolvidos durante aulas de desenvolvimento web no ensino médio.

Os projetos abordam conceitos fundamentais de front-end, incluindo HTML, CSS, JavaScript e Bootstrap, com foco em prática e aprendizado progressivo.

## Conteúdos estudados
- HTML básico e estruturação de páginas
- CSS e estilização de elementos
- Flexbox
- JavaScript básico
- Bootstrap e layouts responsivos

## Estrutura do repositório
- **html-css-basico**: exercícios iniciais de HTML e CSS
- **html-css-js-flexbox**: introdução ao JavaScript e Flexbox
- **bootstrap-introducao**: primeiros projetos usando Bootstrap
